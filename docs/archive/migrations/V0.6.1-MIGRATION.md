# v0.6.1 结构迁移说明

v0.6.1 将原来分散在 `systems/character`、`systems/profession`、`systems/skill`、
`systems/progression`、`systems/inventory`、`systems/item`、`systems/warehouse`
等目录的相关模块重新按业务域收口。

完整源码包 `TonightDefense-v0.6.1.zip` 不需要执行任何迁移脚本。

如果从 v0.6.0 使用增量包：

1. 关闭 Cocos Creator。
2. 将 `TonightDefense-v0.6.1-patch.zip` 直接覆盖到 v0.6.0 项目根目录。
3. 运行 `scripts/migrations/Apply-v0.6.1-Patch.bat`。
4. 脚本只删除 v0.6.0 已确认废弃的旧文件，并且只移除已经为空的旧目录，不递归删除未知用户文件。
5. 脚本最后运行项目 Safety Gate；通过后再用 Cocos Creator 3.8.8 打开项目。

迁移中所有仍被使用的 Cocos `.meta` 文件随源码移动并保留原 UUID。
