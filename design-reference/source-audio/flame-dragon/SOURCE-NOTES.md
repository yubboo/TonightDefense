# Flame Dragon source audio

This directory preserves the source material supplied for the Flame Dragon boss so GitHub and browser-based collaborators can inspect it instead of inventing replacement audio.

- `龙吼+飞翔_爱给网_aigei_com.mp3` is the source of the runtime clip at `assets/resources/audio/sfx/flame_dragon_roar.mp3`; the two files have the same SHA-256 hash.
- `龙吼声_looperman.wav` is an alternate source candidate and is not loaded by the game at runtime.
- `赤金炎龙_Boss音效_CC0采集清单.zip` and `赤金炎龙_Boss音效_CC0精选_v3.zip` preserve the collected links, notes, and license/source documentation.

Do not replace the runtime clip automatically. Review source/license notes and test the result in Cocos Creator 3.8.8 before changing it.
